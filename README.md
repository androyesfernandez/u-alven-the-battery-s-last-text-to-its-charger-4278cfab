A dying phone battery sends its charger a formal resignation text: it expires at 1% and asks the charger to stop telling people they were "basically together" — they were never plugged in.

## Run

`node main.ts` writes the entry line to `/output/entry.txt`. Requires Node 22. No dependencies, no network.
